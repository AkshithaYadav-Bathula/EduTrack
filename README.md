# EduTrack
EduTrack is a web application that shows colleges on a map and tracks how many students have registered and completed their courses. It helps educators and policymakers monitor student progress in different colleges using an easy-to-use, interactive interface.

🛠️ Technology Stack & Design
HTML: Structures the web page and defines the layout of the map and student statistics.
CSS: Enhances the user interface with styling, making it visually appealing and responsive across devices.
JavaScript: Powers interactivity, dynamically fetching and displaying data from a JSON file and integrating mapping functionalities.
JSON: Stores college details, including latitude, longitude, student registrations, and course completion stats.
Map APIs(Google Maps API): Enables real-time display of colleges on an interactive map.
